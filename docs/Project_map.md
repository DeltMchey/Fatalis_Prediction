## 1. 项目概述

BlackDragon 是一个基于内存读取 + 机器学习的《怪物猎人世界》AI 辅助狩猎工具，专为终局 Boss **黑龙（Fatalis）** 设计。

**核心能力**：实时读取游戏内存 → 解析战斗状态 → LightGBM 预测 Boss 下一招 → 透明悬浮窗展示。

**技术栈**：`pymem`（内存读取） + `dearpygui`（悬浮窗） + `LightGBM`（模型） + `pandas/numpy`（数据处理）

### 3.2 关键数据变换节点

| 节点 | 输入 | 输出 | 变换逻辑 |
|------|------|------|----------|
| 动作合并 | raw_action_id (动画帧 ID) | base_action_id (起手式 ID) | `ACTION_MAPPING` 字典查表，如 38→37 |
| 姿态追踪 | action_id 序列 | posture ∈ {0,1,2,3,4} | 状态机：特定招式触发姿态切换 |
| 派生提取 | 逐帧 CSV | (状态, 上一招) → 下一招 | 仅当 frame[t].action ≠ frame[t-1].action 且过滤无效招式时记录 |
| 物理过滤 | 模型概率向量 + phase/posture | 过滤后概率向量 | 阶段不符/姿态不符的招式概率归零 → 重归一化 |
| 发怒检测 | 怪物内存 +0x1BE30 | is_enraged ∈ {0,1} | `0 < enrage_timer < enrage_max` |

### 4.2 训练超参数说明

| 参数 | 值 | 作用 |
|------|-----|------|
| `num_leaves=63` | 叶节点数 | 控制模型复杂度，63 配合 max_depth=7，避免过拟合 |
| `max_depth=7` | 树深度 | 限制树深度防止过拟合 |
| `learning_rate=0.03` | 学习率 | 较小学习率配合 300 棵树 |
| `n_estimators=300` | 树的数量 | 配合 early_stopping 实际可能早停 |
| `subsample=0.8` | 行采样 | 每棵树随机 80% 样本，防过拟合 |
| `colsample_bytree=0.8` | 列采样 | 每棵树随机 80% 特征 |
| `class_weight='balanced'` | 类别权重 | 自动平衡稀有招式与常见招式的权重 |
| `early_stopping=15` | 早停轮数 | 验证集 loss 连续 15 轮不降则停止 |

### 4.3 训练数据规模

| 指标 | 数值 |
|------|------|
| 原始录制文件 | 17 个 |
| 原始数据总大小 | ~11 MB |
| 清洗后样本数 | 数千条派生对 |
| 特征维度 | 6 |
| 招式类别数 | ~40-60 个（取决于过滤后） |
| 每类最少样本 | ≥3（训练前过滤） |
