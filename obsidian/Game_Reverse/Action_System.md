# Action System

## 概述

BlackDragon 的动作系统定义在 `src/config/actions.py`（唯一数据源）。包含动作数据库、映射规则、阶段/姿态分类和战斗参数。

## 动作数据库（ACTION_DB）

```python
ACTION_DB: dict[int, str] = {
    306: "等待", 307: "等待", 308: "等待",
    309: "开场吼", 4: "怒吼", 5: "怒吼",
    30: "趴下", 28: "转身后退", 21: "索敌", ...
    # 共 144 条映射
}
```

**用途**: 将游戏内存中的数字 ID 翻译为人类可读的中文招式名。

## 动作合并映射（ACTION_MAPPING）

### 为什么需要合并

游戏引擎在每个动画**帧**都暴露一个 action_id。同一个攻击动作的不同帧有不同 ID。如果不合并，模型会学到大量"假转移"（如龙车帧1→龙车帧2→龙车帧3）。

### 映射规则

```
动画帧 ID（多帧） ──ACTION_MAPPING──▶ 起手式 Base ID（1 个）
```

### 使用场景

- **ai_engine.py**: 推理时将 `raw_action_id` 合并为 `base_action_id` 后作为 `previous_action` 特征输入模型
- **data_cleaner.py**: 清洗时合并，确保派生对提取正确

## 阶段专属招式分类

### P1 专属招式（P1_ONLY_IDS）

P2/P3 阶段不再使用的招式。Phase > 1 时概率归零。

```python
P1_ONLY_IDS = {37, 38, 39, 40, 53, 54, 55, 56, 146, 147, 148, 137}
# 龙车(立)、连咬(立)、后撤(立)、孕吐(趴)
```

### P2+ 新增招式（P2_PLUS_IDS）

Phase ≥ 2 才解锁的招式。Phase < 2 时概率归零。

```python
P2_PLUS_IDS = {
    129, 119, 121, 122, 138, 49, 50, 51, 52,
    68, 69, 70, 71, 72, 149, 150, 151, 81, 82, 83,
}
# 蓄力火、飞天俯冲、孕吐(立)、龙车(趴)、连咬(趴)、后撤(趴)、吐痰
```

### P3 专属招式（P3_ONLY_IDS）

Phase = 3 才解锁的招式。Phase < 3 时概率归零。

```python
P3_ONLY_IDS = {
    100, 101, 98, 99, 155, 156, 134,
    208, 209, 210, 214, 211, 213, 215, 212, 216,
}
# 三连蓄力火、360度扫火、左右火、捕食
```

DOWN_IDS = {75, 221, 232, 236, 237, 241, 242, 245, 246, 249, 278, 279, 280}

## 战斗参数（NOVA_THRESHOLDS）

```python
NOVA_THRESHOLDS = [0.78, 0.50, 0.41, 0.26, 0.06]
# HP ≤ 78% / 50% / 41% / 26% / 6% 触发飞天火预警
```

| 阈值 | HP% | 含义 |
|------|-----|------|
| 0.78 | ≤78% | P1→P2 转阶段 |
| 0.50 | ≤50% | P2→P3 转阶段 |
| 0.41 | ≤41% | P3 第一次 Nova |
| 0.26 | ≤26% | P3 第二次 Nova |
| 0.06 | ≤6% | P3 第三次 Nova（最终） |
